The site is static HTML/CSS with Markdown reading sources. Existing GitHub Pages deployment uses `main` → `/docs`. No calculation engine, plugin source, compiled plugin, restricted dataset files, private meeting notes or project models are bundled.

Research notebooks are dated snapshots; older proposals are not current API documentation. The icon family is approved for testing, not finally approved aesthetically. Original research is retained in the private working repository. Third-party references remain attributed and linked to official sources.

This repository is public. Its existing [licence status](LICENSE.md) remains unchanged; publication does not grant an open-source software licence or rights to third-party data/artwork.

Material Catalogue V1 publishes attributed, unchanged ÖKOBAUDAT field excerpts under its official free-distribution terms. Danish records are withheld individually pending bulk-redistribution clearance; their aggregate audit and a bounded case study are public. Catalogue analysis is separate from source values. See [publication policy](docs/notebooks/raw-material-catalogue-audit.html#publication).
