RAW Construct Element

Combines geometry and material with optional dimensional data into an analytical element and known quantities.

Not a Windows window; no GWP calculated here. Unit/count remains legacy-only.

Current compact interface

Inputs: Geometry; Material: DatasetAssignment; Surface Thickness with explicit unit; Linear Section.

Outputs: Elements: EnvironmentalElement. Optional resolved quantities.

Solid volume, area × thickness or length × section. No missing density inferred. Geometry and scalar units are separate. Single material broadcast and corresponding lists/branches require unambiguous alignment.

Use and limitations

Optional and mode-specific ports may remain serialized when hidden. Inspect quantities, source provenance and coverage before interpreting results. A missing input is not an inferred zero.
