RAW Emissions

Current compact interface

Inputs: Optional exposed physical quantities per batch.

Outputs: Emissions: EmissionList; optional Summary.

Editor preserves substance identity and compartment. Physical emissions are separate from kg CO₂-eq supplied impacts. Missing direct-emission data is not confirmed zero.

Use and limitations

Optional and mode-specific ports may remain serialized when hidden. Inspect quantities, source provenance and coverage before interpreting results. A missing input is not an inferred zero.
