RAW Ingredients

Current compact interface

Inputs: Materials: list of DatasetAssignment; optional exposed quantities in selected units per batch.

Outputs: Ingredients: IngredientList; optional Summary.

Editor rows retain identities and source bindings. Add connected material explicitly binds a row. Wired quantities override stored values. A disconnected source never becomes a different material automatically.

Use and limitations

Optional and mode-specific ports may remain serialized when hidden. Inspect quantities, source provenance and coverage before interpreting results. A missing input is not an inferred zero.
