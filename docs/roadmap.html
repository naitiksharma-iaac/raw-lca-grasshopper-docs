Roadmap

Validate first, then build.

This sequence is exploratory, not a delivery commitment. No finished plugin is released yet.

1 · Scope and validation

Define the minimum workflow, scientific boundaries, provenance requirements, and reference cases.

2 · Local-first V1

Explore geometry-to-quantity, local user-managed records, scenario comparison, and traceable exports. No server and no bundled environmental dataset.

3 · Documentation

Document every component’s inputs, outputs, units, assumptions, warnings, and limitations.

4 · Interoperability

Explore LCAx, ILCD+EPD, openEPD, and API connectors with explicit mappings and permissions.

5 · Conditional hosting

Explore a hosted platform only if funding and licensing allow. It must not become a V1 requirement.

6 · Release gate

Complete validation, licensing, attribution, documentation, and a public-safety audit before any software release.
