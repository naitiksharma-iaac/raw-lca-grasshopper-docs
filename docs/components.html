Components

Proposed building blocks.

These names describe a possible workflow. Nothing listed here is implemented or released.

No finished plugin is released yet, and no default environmental values or dataset are bundled.

Material record

Represent a permitted EPD or material record with provenance, units, scope, and review status.

Geometry to quantity

Extract volume, area, length, mass, or count while exposing conversions and assumptions.

Scenario

Group quantities, materials, processes, and explicit assumptions into a comparable alternative.

Calculate

Apply validated calculation rules and report missing or incompatible information.

Compare

Compare compatible scenarios while keeping boundaries and limitations visible.

Export

Export results together with provenance, assumptions, units, and version information.

Documentation requirement

Any future component should document purpose, inputs, outputs, units, assumptions, validation, warnings, limitations, and a permitted example.
