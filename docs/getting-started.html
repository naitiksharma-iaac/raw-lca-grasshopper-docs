Getting started

No cleared public package is available yet. This describes the intended installation and current collaborator workflow, not a tested external installer.

Requirements

Windows, Rhino 8 running .NET 8 and Grasshopper. Current SDK references: 8.31.26126.13431.

When a package is released

  1. Verify its checksum, version and notices.
  2. Close Rhino; extract the whole package and unblock downloaded files if Windows requires it.
  3. Open Grasshopper File → Special Folders → Components Folder; install one RAW version with its dependencies.
  4. Restart and confirm Materials, Elements, Impact and Visualisation under RAW LCA.
  5. Open the matching example.

First exercise

  1. Select a material with a supported m³ declared unit and available factor.
  2. Connect a closed solid and Material to Construct Element in Volume mode.
  3. Connect Elements to Element GWP.
  4. Inspect GWP and Result coverage.

Expected arithmetic: measured volume / declared volume × source factor. A kg-based material additionally needs evidenced mass or density. Missing is not zero.

Troubleshooting

Loading errors: check host runtime, duplicate assemblies and dependencies. Null GWP: inspect factor, quantity, supplier and scope diagnostics. Close Rhino before replacing locked assemblies; remove only the RAW installation package to uninstall. Keep your definitions and backups.
