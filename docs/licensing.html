Licensing

Code and data have separate terms.

Software licensing and data licensing are separate. A software license cannot grant rights to third-party environmental data.

The software license is not yet selected. No finished plugin is released yet.

Public repository policy

  • No environmental dataset is bundled.
  • ecoinvent-derived data is not included.
  • No restricted datasets, credentials, or API keys may be committed.
  • Public availability of an EPD or dataset does not automatically permit redistribution.
  • Synthetic examples must be labelled and must not be presented as environmental evidence.

Before a software release

Select an appropriate software license, confirm contributor rights and attribution, validate all examples, and review the full Git history for restricted or private material. This is project policy, not legal advice.
